ABOUT THE PROJECT

Mapping Lunar Correspondence

LUNARMATCH is a web interface for a lunar image correspondence pipeline designed around Chandrayaan-2 imagery.

The system connects an interactive frontend with a Python-based computer vision backend to identify corresponding features between lunar surface images.
